Alicia en el país de las maravillas
Descripción del proyecto
Este proyecto consiste en una página web interactiva inspirada en la historia Alicia en el país de las maravillas. Se desarrollaron tres ejercicios utilizando HTML5, CSS3 y JavaScript, aplicando formularios, validaciones, estructuras de control, ciclos y manipulación del DOM.

El objetivo es demostrar el funcionamiento de estas tecnologías mediante situaciones relacionadas con los personajes y elementos del cuento.
Objetivos
1. La poción de Alicia
Este ejercicio calcula la altura final de Alicia después de beber una poción mágica.

Funcionamiento:
1. El usuario introduce la altura inicial de Alicia en centímetros.
2. Introduce la cantidad de poción en mililitros.
3. El programa valida que los datos sean correctos.
4. Calcula la altura final.
5. Compara el resultado con la altura de una puerta de 180 cm.
6. Muestra si Alicia puede pasar por la puerta.
Fórmula utilizada:

Altura final = Altura inicial + (Cantidad de poción × 2)

Estructuras utilizadas:
- if
- else if
- else
- Funciones de JavaScript
- Validación de datos
- Manipulación del DOM
2. La merienda del Sombrerero Loco
Este ejercicio calcula el costo de una merienda según la bebida seleccionada y la cantidad de tazas.

Bebidas y precios:
Bebida	Precio por taza
Té	Bs 5
Café	Bs 8
Chocolate	Bs 10
Limonada	Bs 6

Funcionamiento:
1. El usuario introduce su nombre.
2. Selecciona una bebida.
3. Introduce la cantidad de tazas.
4. El programa valida los datos.
5. Calcula el subtotal.
6. Aplica un descuento del 10 % cuando se compran cinco tazas o más.
7. Muestra el detalle de la compra y el total a pagar.
Estructuras utilizadas:
- switch
- if y else
- Funciones de JavaScript
- Validación de formularios
- Operaciones aritméticas
- Manipulación del DOM
3. La Reina de Corazones
Este ejercicio analiza una secuencia de números enteros positivos desde 1 hasta el número introducido por el usuario.

Funcionamiento:
1. El usuario introduce un número entero positivo.
2. El programa valida que el número esté entre 1 y 100.
3. Recorre los números desde 1 hasta el número ingresado.
4. Identifica cuáles son pares y cuáles son impares.
5. Cuenta los números pares e impares.
6. Calcula la suma de cada grupo.
7. Compara las sumas y muestra cuál es mayor o si son iguales.
Estructuras utilizadas:
- Ciclo for
- Condicional if y else
- Contadores y acumuladores
- Funciones de JavaScript
- Validación de datos
- Manipulación del DOM
